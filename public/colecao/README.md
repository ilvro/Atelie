# Coleção da Casa (Ateliê)

Esta coleção é gerada e populada pelos scripts das etapas 12 a 16 (papéis, elementos, fontes e modelos).
Ela pertence ao próprio Ateliê de Documentos e faz parte do repositório público versionado no Git.

Os manifestos e arquivos desta pasta são servidos de forma estática para o aplicativo.
Expansões privadas (como os Arquivos Confidenciais) nunca devem ser colocadas aqui; elas residem exclusivamente em `data-private/expansoes/`.
