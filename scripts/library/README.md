# Scripts de importação da biblioteca

Esta pasta conterá os scripts de importação de elementos e modelos (etapas 22, 23 e 25):
- `import-elements.js`: importa imagens, símbolos e fontes para a expansão local.
- `psd-report.js`: analisa e gera relatórios sobre a estrutura dos PSDs.
- `import-psd.js`: converte PSDs em modelos editáveis do Ateliê.
